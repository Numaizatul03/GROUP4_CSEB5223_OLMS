# 7. Function / Method Modularity 

The Online Local Mart System shall apply function and method modularity to keep the source code organized, reusable, and easy to maintain.

- Each function or method should perform one clear task. 
- Large functions should be divided into smaller and reusable functions.
- Functions and methods should use meaningful names.
- Repeated code should be avoided by using reusable functions.
- Functions should follow the naming conventions defined for the project.
- Related functions should be placed in the appropriate class or module.

# 8. Communication Rules

The project team shall follow clear communication rules to ensure that tasks are coordinated properly and that conflicts are minimized.

- Team members should communicate regularly about assigned tasks and progress.
- Major changes that may affect other members should be discussed before implementation.
- Members should inform the team when important changes are pushed to GitHub.
- Problems or errors should be reported to the team as early as possible.
- Team members should avoid modifying another member's work without prior communication.
- Merge conflicts should be discussed and resolved together.

# 9. Continuous Integration Rules

The Online Local Mart System shall use GitHub to manage and integrate work contributed by different team members.

- Each team member shall work on a separate branch for their assigned tasks.
- Team members shall not commit directly to the `main` branch.
- The `main` branch shall contain the latest reviewed and stable version of the project.
- Clear and meaningful commit messages shall be used.
- Completed work shall be reviewed before being merged into `main`.
- Code or documentation with known errors or incomplete work shall not be merged into `main`.
- Merge conflicts shall be resolved before completing the merge.
- Team members should obtain the latest version of the project before integrating new changes.
- The repository should be updated regularly so that all team members have access to the latest work.
- The team leader shall monitor and coordinate important merging activities.
